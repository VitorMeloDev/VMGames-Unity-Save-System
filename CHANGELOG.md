# Changelog
All notable changes to this package will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/)

## [0.1.0] - 2026-10-28

### Added

- Generic service for asynchronously saving and loading data.
- Replaceable serialization and storage interfaces.
- Local file storage strategy and JSON serializer using `UnityEngine.JsonUtility`.
- Integration test for writing and reading data from disk.
